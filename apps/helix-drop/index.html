玩法說明

  • 在畫面任意處左右拖曳旋轉糖果塔（電腦可用 ← → 或 A / D）。
  • 球碰到糖片會彈起；讓它從缺口掉下去，每穿過一層得「連穿數」分。
  • 辣椒熔漿一碰就碎！
  • 連續穿過 3 層進入穿透狀態：下一次落地會直接砸碎平台，連熔漿也不怕。
  • 每 25 層有一層金色彩蛋平台：落上去 +10 分並換一套糖果配色。
  • 越往下：熔漿會流動（15 層）、缺口會開合（35 層）、出現下方是熔漿的陷阱缺口（55 層）、平台反向自轉（80 層）。
  • 難度 = 1 + 層數 ÷ 10。
