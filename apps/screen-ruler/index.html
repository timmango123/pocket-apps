校準

瀏覽器無法得知螢幕的實際像素密度。用實物對齊一次，之後的公分刻度才準確。

把實體信用卡（85.60 × 53.98 mm）貼在螢幕上，拖曳右下角或用滑桿調整，直到框線與卡片邊緣對齊。

PPI = √(寬² + 高²) ÷ 對角線吋數；每公釐 CSS 像素 = PPI ÷ 25.4 ÷ 裝置像素比。

外觀

背景說明：淺色主題底色為淺灰白，深色主題為近黑，量測刻度在兩種主題下都清楚；需要純黑或純白襯底時，切換主題即可。

其他

本工具不使用相機、麥克風或任何感測器。取色在支援 EyeDropper 的桌面瀏覽器可直接取螢幕顏色，其他裝置請載入截圖取色。
