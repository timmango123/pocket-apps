公式與說明
  • 薄透鏡成像：1/f = 1/u + 1/v。對焦距離 s 決定感光元件到鏡頭的距離 vₛ = 1/(1/f − 1/s)。
  • 物距 u 的點成像於 vᵤ，在感光元件上散成直徑 b = D·|vᵤ − vₛ|/vᵤ 的模糊圈，其中光圈口徑 D = f/N。
  • 允許模糊圈（看起來仍算清晰）取 c = 對角線 ÷ 1500，全片幅約 0.029 mm。
  • 超焦距 H = f²/(N·c) + f；景深近界 Dₙ = s(H−f)/(H+s−2f)，遠界 D_f = s(H−f)/(H−s)（s ≥ H 時為 ∞）。
  • 對焦在超焦距時，從 H/2 到無限遠都清晰——風景攝影常用的技巧。
  • 換小片幅但維持相同視角，需要更短的焦距，景深因而變深；「等效光圈」= N × 裁切係數，可以用來比較背景虛化。
  • 畫面模糊以每個物體的模糊圈直徑換算成像素繪製；點光源（路燈、燈串）直接畫成散景圓盤，收光圈時會出現光圈葉片的多邊形。
