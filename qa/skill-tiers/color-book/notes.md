# 填色本（color-book）技能分級測試

填色本沒有輸贏，所以這裡比的是**效率與挫折**：塗完一張要多少（模擬的人類）時間、點錯幾次、空點幾次、要縮放幾次、什麼時候需要提示、哪裡會卡住。
bot 用 390×844 手機情境、CDP 真實觸控（點、雙指捏合、單指拖曳、點色票／提示／全圖按鈕）。它讀 `__cb.state()` / `__cb.regions()` 模擬「眼睛看到的畫面」，但所有操作都經由觸控事件。
時間是模擬值：反應時間 + 找下一塊的時間 + 手勢時間 + Fitts 式瞄準時間；牆鐘上限每張 480 秒。

## 觀察
- 曲線平滑：每塊秒數由手殘約 4.4 → 普通 2.3 → 熟練 1.5 → 世界級 1.0，跟圖的塊數幾乎成正比，相鄰測試圖之間沒有斷層。
- 小區塊在手機上都摸得到：手殘每 100 塊要縮放約 52 次、世界級約 8 次，但沒有任何一塊是放大到上限還點不到的。磁吸（點到線上或已塗的地方時，22px 內同色未塗的一塊）讓空點維持在每 100 塊 7 次以下。
- 提示幾乎用不到：全部 35 次中提示總共 5 次，都在 168 塊以上的圖；選了顏色後未塗的區塊會變灰，很容易找。
- 「卡住」= 同一塊連點 3 次沒塗上。手殘 3 次、熟練與世界級各 1–2 次，全部出現在 4px 以下的碎塊；每次點錯都會跳出號碼泡泡，下一下就塗上了。
- 測試中沒有頁面錯誤或 console 錯誤。
