# 高壓洗淨 — 技能分級測試

測試環境：Chromium 無頭，390×844 @2 觸控。rAF 改為鎖步，每幀 1/30 秒。關卡 1/10/25/50/75/99/100。表中時間為遊戲內秒數。

| 分級 | 過關 | 各關時間 (L1/10/25/50/75/99/100) | 星數 | 平均洗淨速度 (%/分) |
|---|---|---|---|---|
| 手殘 | 7/7 | 91 / 83 / 101 / 140 / 172 / 91 / 218 | 全 3 星 | 52.7 |
| 普通 | 7/7 | 49 / 52 / 76 / 93 / 115 / 63 / 168 | 全 3 星 | 80.9 |
| 熟練 | 7/7 | 58 / 80 / 78 / 104 / 241 / 56 / 288 | L75 2 星，其餘 3 星 | 66.5 |
| 世界級 | 7/7 | 64 / 78 / 53 / 72 / 80 / 39 / 94 | 全 3 星 | 94.6 |

## 發現
1. **中：難度曲線幾乎是平的。** 手殘玩家第 100 關 218 秒就過關並拿到 3 星（限時 358 秒，3 星目標 310 秒）。非人玩家 41 秒過關。原因是 par 與時間／水量上限的估算（index.html:582-584）假設玩家慢慢掃過一次，但手指快速來回刷的效率高出 2–7 倍。建議改用快速刷洗的實測值來校正 par 和 budget。
2. **中：清洗力道會隨幀率和筆畫速度改變。** spray() 裡的 `f = clamp(1.6/cnt, 0.4, 1)`（index.html:659）讓單幀印章數越多，總劑量越大。同一筆畫在 L50 刷 6 趟（1500 px/s）：30fps 洗掉 4.0%，60fps 3.75%，120fps 0%。用同一策略打整關 L50：30fps 106 秒過關，60fps 到時間只洗到 69.5%，失敗。120Hz 手機上的玩家會明顯吃虧。建議改為 `f = 1/cnt`，讓每點劑量只取決於噴嘴停留時間，再一併重調參數。
3. **低：仔細玩沒有好處。** 效率幾乎只取決於刷得多快。逐列確認的熟練 bot 反而比亂刷的普通 bot 慢。
4. 手殘干擾共 97 次（第二根手指、連點、轉橫向再轉回、切到背景 2 秒），沒有出現錯誤、卡住噴水或指標遺失。
