# 數回（slitherlink）技能分級測試

- **環境**：真實 Chromium，390×844，觸控。機器人只透過 CDP 觸控事件操作：點邊、從點拖到點畫線、雙指縮放和平移、點「檢查」和「復原」。
- **讀取盤面**：透過 `window.__game` 讀取畫面上看得到的資訊。
- **測試關卡**：1、10、25、50、75、99、100。
- **嘗試次數**：手殘最多 5 次，其他等級最多 3 次。
- **時間上限**：每次嘗試以「3 倍 3 星時間 + 2 分鐘」為上限。用的是虛擬時鐘，思考和反應時間照等級累計。

## 各等級的推理能力

| 等級 | 會的推理 | 每步思考 | 推理出錯率 |
|---|---|---|---|
| 手殘 | 0、數字已滿、數字要全畫、不能分岔、死路 | 2.6 秒 | 15% |
| 普通 | ＋不能提早封閉 | 1.5 秒 | 6% |
| 熟練 | ＋斜角推理 | 1.0 秒 | 2% |
| 世界級 | ＋假設法（最多 20 步） | 0.65 秒 | 0.3% |
| 非人 | 已知答案，一筆拖完整圈 | 0 | 0 |

- **卡住時**：在線頭猜一條線。
- **自己推出矛盾時**：按「檢查」。
  - 有紅色標示就擦掉。
  - 找錯次數用完後，退回最後一次猜測之前並改成打 ✕；沒有猜測紀錄就退回 4–12 步。
  - 連續幾次都沒有進展就放棄這次嘗試（手殘 3 次，普通 4 次，熟練 5 次，世界級 6 次）。
- **點擊誤差**：數回的點擊是瞄準不動的目標，沒有時間壓力，所以位置誤差用 harness 的 0.3 倍（手殘 12px，普通 6px）。這點和 SPEC 不同，原因寫在 bot.js 的 `AIM`。
- **縮放**：盤面格子太小時，各等級會先雙指放大到習慣的格子大小（手殘 58px，普通 48px，熟練 40px，世界級 34px），再平移操作。

### 曲線抽測（找相鄰關卡之間有沒有牆）

- **手殘**：L13 ✔、L16 ✘、L19 ✔（第 3 次）、L22 ✘、L25 ✘。
  - 從第 16 關開始有找錯次數限制，手殘是在 L13 到 L25 之間逐漸失手，不是在某一關突然全滅。
- **普通**：L31 ✔、L37 ✔、L43 ✘（3 次）、L50 ✘。
  - 第 37 關開始引入假設法，普通在 L37 還能靠猜測過，到 L43 以後就過不了。

### 其他

- **連點**：每秒 8 下，共 24 下，交替點兩條邊。24 下都只算一次，undo 24 步，兩條邊都回到空白。
- **錯誤**：整輪 0 個 page error，0 個 console error。
- **誤觸**：手殘每關 11–57 次，普通 0–4 次，熟練和世界級 0 次。
- **實際耗時**：全部跑完 113 分鐘，加上抽測約 40 分鐘，超過 SPEC 建議的 30–40 分鐘。
  - 主要花在手殘和普通的大盤面放棄前的嘗試。
  - 中途被 session 中斷過一次，最後整輪從頭重跑。

## 發現與處理（細節見 fixes.md）

- **高（已修）**：放大後右上角被「縮回全圖」按鈕蓋住，拖曳從那裡起手會被按鈕吃掉。熟練 L99 有 1093 次點擊沒反應，花了 47 分鐘。
- **中（已修）**：「檢查」和「提示」都能無限找錯，手殘靠猜加對答案過了 L75 和 L99。改成找錯次數共用、依盤面大小給，前 15 關不限。
- **中（已修）**：L1 的教學提示框在拖曳中重新排版，非人 L1 三次都差 1 條線。
- **低（已修）**：最忙時的 FPS 從 10–14 拉到 45–57。
- **低（未修）**：技巧差異集中在普通到熟練之間。熟練不會假設法，靠猜加 25 次找錯，仍能過 99/100。
  - 熟練和世界級的差別是時間和猜測次數：L99 熟練猜 23 次，世界級 0 次。
  - 這符合「世界級幾乎全過、非人全過」，不另外調整。
- **低（未修）**：後段的 3 星時間偏寬，世界級只用了約 40%。
